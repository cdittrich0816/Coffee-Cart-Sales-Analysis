# Coffee Cart Sales Analysis

## Repository layout
```
data/raw/coffee_sales.csv   # raw data, untouched
notebooks/analysis.ipynb     # the pipeline: fixed, runs linearly top-to-bottom
output/                      # generated chart (created by the pipeline)
```

## Setup
```
pip install -r requirements.txt
```

## Run
```
jupyter nbconvert --to notebook --execute notebooks/analysis.ipynb
```
This reads `data/raw/coffee_sales.csv`, prints daily revenue, average daily
revenue, the group A/B split comparison, and revenue by product, and saves
`output/revenue_by_product.png`. Running it this way (rather than opening it
and clicking through cells) is what makes it a one-command, no-manual-steps
pipeline.

## Fixes applied to the original notebook
The original `messy_analysis.ipynb` only worked on its author's machine
because of a few reproducibility issues:
- **Hardcoded paths** (`/Users/jmwaura/Desktop/analysis/...`) — I replaced with
  paths relative to the repo root (`Path.cwd().parent`), so it works from any
  clone.
- **Cell-order dependency** — the "Average Daily Revenue" cell printed
  `avg_daily` before the cell that computed it existed further down. Reordered
  so `daily`/`avg_daily` are computed first.
- **Unseeded randomness** — `df.sample(frac=1)` gave a different 50/50 split
  (and different group means) on every run. Added `random_state=42`.

Verified by executing the notebook non-interactively with `nbconvert
--execute` from a fresh clone and confirming identical output across runs.
