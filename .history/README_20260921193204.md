# Coffee Cart Sales Analysis

## Repository layout

data/raw/coffee_sales.csv # raw data, untouched
notebooks/analysis.ipynb # the pipeline
output/ # chart generated by the pipeline

## Setup

pip install -r requirements.txt

## Run

jupyter nbconvert --to notebook --execute notebooks/analysis.ipynb

This reads `data/raw/coffee_sales.csv`, prints the daily revenue, average daily
revenue, the group A/B split comparison, and revenue by product, and saves
`output/revenue_by_product.png`. Running it this way (as opposed to opening it
and clicking through cells) is what makes it a pipeline that requires no
manual steps.

## Fixes applied to the original notebook

The original `messy_analysis.ipynb` only worked on the machine of its author
because of a few reproducibility issues:

- **Hardcoded paths** (`/Users/jmwaura/Desktop/analysis/...`) — I replaced this
  with paths relative to the root of the repo so it works from any clone.
- **Cell-order dependency** — the cell that attempted to print the average daily
  revenue `avg_daily` existed before the cell that actually computed it. I fixed the
  order so `daily`/`avg_daily` are computed first.
- **Unseeded randomness** — `df.sample(frac=1)` yielded a different 50/50 split
  on every run, so I added `random_state=42`.

I verified everything by cloning the repository into a fresh folder and running the notebook
using the `nbcconvert --execute`command above. This confirmed that the output was identical 
across runs.
